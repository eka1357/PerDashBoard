# AGENTS.md — Personal Dashboard Project

## Project Overview
A modular, extensible personal dashboard built with **React, Vite, Tailwind CSS, and Lucide Icons**. The architecture is optimized for "vibe coding" in agent-first environments like Google Antigravity, structured explicitly so new widgets can be cleanly "bolted on" over time without refactoring core components.

## Tech Stack & Architecture
- **Framework:** React 18+ (Vite)
- **Styling:** Tailwind CSS
- **Icons:** `lucide-react`
- **State/Persistence:** React Hooks backed by `localStorage`
- **Project Layout:**
  ```text
  src/
  ├── components/
  │   ├── common/       # Layout, Navbar, Grid container
  │   └── widgets/      # Self-contained feature modules
  │       ├── Weather/
  │       ├── Todos/
  │       ├── Quotes/
  │       └── Habits/
  ├── hooks/            # Custom reusable hooks (useLocalStorage, etc.)
  └── utils/            # API helpers and formatters
